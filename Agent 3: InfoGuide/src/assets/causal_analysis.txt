CausalLens: SmartPilot Causal Agent
1 Overview
The Causal Agent in the SmartPilot system is a robust module designed for discovering,
validating, and utilizing causal relationships among variables in industrial manufacturing
datasets. This component is central to enabling counterfactual reasoning, explainability,
and root cause analysis (RCA) in an intelligent co-pilot framework. The agent integrates
machine learning, causal inference, and symbolic reasoning to support critical decision-
making processes.
SmartPilot’s causal capabilities are powered by:
• LiNGAM (Linear Non-Gaussian Acyclic Model)
• DiffAN (Differentiable Causal Discovery with Attention)
• Bootstrapped Stability Analysis
• Counterfactual Evaluation using Observational Data
• Interactive Graph Construction and Modification
These methods are tied into a user-facing Streamlit interface that supports intuitive
data uploads, feature selection, and causal graph interaction.
2 Algorithms and Methods
2.1 DirectLiNGAM
DirectLiNGAM is a linear, non-Gaussian, and acyclic causal discovery algorithm. It
learns a Directed Acyclic Graph (DAG) by identifying a causal ordering of variables.
Procedure:
1. Input: Data matrix X ∈Rn×d
2. Assumptions:
• Linear SEM: Xj= i<j bjiXi + ej
• ej are non-Gaussian and independent
3. Output: Adjacency matrix A encoding bji
2.2 DiffAN
DiffAN (Differentiable Causal Discovery with Attention and Normalization) is a deep
learning-based method for causal structure learning using attention maps.
Procedure:
1. Input: Dataset with selected variables
2. Architecture:
• Learns soft attention weights between variable pairs
• Applies edge normalization and regularization
• Generates causal matrix via differentiable optimization
3. Output: Directed graph with weighted edges

3 Integration with SmartPilot UI
3.1 Causal Discovery Interface
• Upload dataset and select features
• Run LiNGAM and DiffAN with dynamically generated scripts
• Add/remove nodes and edges interactively
3.2 Causal Graph Visualization
Rendered with PyVis:
• Tooltips from ontology/KG
• Edge weights from bootstrap/counterfactual evaluation
3.3 Natural Language Querying
Supports queries like:
• “What is the strongest cause of X?”
• “Does A cause B?”
• “If A were set to 10, what happens to B?”
• “What are the parents of Y?”
4 Root Cause Analysis (RCA) Integration
4.1 Anomaly Linkage
• Anomaly predictions trigger RCA
• Sensor anomalies identified using per-cycle tolerance ranges
4.2 RCA Method
• Trace causal paths from anomalies to sensors using total effects
• Output strength-ranked root causes
4.3 RCA Query Support
• “What is the most likely root cause of variable B?”
• “Is A a likely root cause of B?”
• “Why is D not a likely root cause of B?”

7 Conclusion
The Causal Agent in SmartPilot transforms raw manufacturing data into actionable
causal knowledge. By unifying statistical discovery (LiNGAM, DiffAN), empirical vali-
dation (counterfactuals), and symbolic explanation (ontology), it enables industrial stake-
holders to understand, validate, and reason about production anomalies and dependencies
in a trustworthy, explainable, and interactive way.
This modular design empowers researchers and engineers to extend, evaluate, and
interact with causal knowledge at multiple levels of abstraction.
